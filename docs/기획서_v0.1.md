## 1. 개요

Claude Agent SDK를 기반으로, Claude Code CLI와 같은 방식으로 쓰되 그래픽 UI와 개인에게 최적화된 단축키를 더한 상주형 데스크톱 앱을 만든다. 여러 프로젝트의 작업을 동시에 맡기고, 키보드만으로 빠르게 오가며 관리하는 것이 핵심이다.

## 2. 확정 사항

- 사용자: 본인 1인 전용 (배포·공유 없음)
- 인증: 구독 계정으로 인증 (API 키 미사용)
- 사용 방식: Claude Code CLI와 동일한 대화 흐름 + 그래픽 UI + 최적화된 단축키
- 실행 형태: 항상 켜져 있는 상주형 앱, 백그라운드에서 계속 작업
- 작업 방식: 사용자가 여러 작업을 동시에 맡기는 방식
- 화면 컨셉: 첫 화면에 프로젝트별 대화창이 나열되고, 키를 눌러 대화창에 들어갔다 나오는 구조
- 같은 프로젝트에서 대화를 동시에 여러 개 돌리는 경우: 많지는 않지만 종종 있음

## 3. 인증·정책 확인 내용 (2026-10-08 공식 문서 기준)

- Agent SDK, `claude -p`, 서드파티 앱은 구독 한도로 사용 가능 (Claude Help Center, "Use the Claude Agent SDK with your Claude plan", 2026-10-07 업데이트)
- Max·Team 플랜은 월간 API 크레딧 포함 (Max 5x $100, Max 20x $200, Team 최대 $500). Agent SDK에 사용 가능, 이월 불가
- 다른 사람에게 제공하는 제품·서비스를 만들 경우에는 API 키 인증 필요 (Claude Code Legal and compliance)
- 환경변수 `ANTHROPIC_API_KEY`가 설정되어 있으면 구독 대신 API 키가 우선 사용되므로 주의
- 구독 한도는 일반적인 개인 사용 기준이므로, 상시 자동 실행 시 한도 소진에 유의
- 정책 변경이 잦으므로 구현 시점에 공식 문서 재확인 필요: https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan

## 4. 화면 구성

### 4.1 홈 화면

- 프로젝트 카드를 그리드로 나열 (최대 9개 노출, `1~9` 숫자키와 대응)
- 카드 표시 정보: 숫자키, 프로젝트명, 상태 배지, 작업 경로, 마지막 응답 1~2줄, 대화 개수, 모드, 경과 시간
- 승인 대기 카드는 홈에서 바로 허용(`Y`) / 거절(`N`) 가능
- 상단 바: 실행 중 개수, 승인 대기 개수, 구독 사용량
- 하단 바: 현재 화면에서 쓸 수 있는 단축키 안내
- 빈 슬롯: 새 프로젝트 추가 (`Ctrl+N`)

### 4.2 대화창

- Claude Code CLI와 같은 대화 흐름 (응답 스트리밍)
- 도구 실행 내역은 카드로 표시 (파일 수정은 diff, 명령 실행 결과는 접기/펼치기)
- 권한 요청은 박스로 표시: 허용(`Y`), 이 프로젝트에서 항상 허용(`A`), 거절(`N`)
- 하위 대화가 여러 개면 상단 탭으로 표시, `Ctrl+Tab`으로 전환
- 다른 프로젝트에 승인 대기가 생기면 우측 상단 배지로 알림
- 입력창: `/` 커맨드 자동완성, `@` 파일 첨부, 현재 모드 표시

## 5. 프로젝트·대화 구조 (제안, 샘플 반영)

- 카드 단위는 프로젝트. 기본은 프로젝트 1개당 대화 1개
- 동시 작업이 필요하면 카드 안에 하위 대화를 추가하고, 카드에 대화 개수 표시
- 카드 상태는 하위 대화 중 가장 급한 것 기준 (승인 대기 > 오류 > 실행 중 > 완료)
- 카드 순서와 숫자키는 프로젝트 기준으로 고정
- 대안 검토: 대화마다 카드를 따로 만드는 방식은 카드 수와 숫자키 위치가 계속 바뀌어 채택하지 않음

## 6. 작업 상태 정의 (초안)

| 상태 | 설명 |
|---|---|
| 대기 | 동시 실행 수 제한으로 대기열에 있음 |
| 실행 중 | 에이전트가 작업 중 |
| 승인 대기 | 권한 요청에 대한 사용자 응답을 기다림 |
| 완료 | 작업 종료 |
| 오류 | 실행 중 오류로 중단 |
| 중단 | 사용자가 `Esc`로 중단 |

## 7. 단축키 맵 (초안)

| 범위 | 단축키 | 동작 |
|---|---|---|
| 전역 | `Ctrl+Space` | 어디서든 앱 호출 |
| 홈 | `1~9` | 해당 프로젝트 대화창으로 들어가기 |
| 홈 | `Y` / `N` | 선택 카드의 권한 요청 허용 / 거절 |
| 홈 | `Ctrl+N` | 새 프로젝트 추가 |
| 공통 | `Ctrl+Shift+A` | 승인 큐 열기 |
| 대화창 | ``Ctrl+` `` | 홈으로 나가기 |
| 대화창 | `Ctrl+Tab` | 하위 대화 전환 |
| 대화창 | `Ctrl+1~9` | 다른 프로젝트 대화창으로 바로 이동 |
| 대화창 | `Esc` | 실행 중인 작업 중단 |
| 대화창 | `Shift+Tab` | 모드 전환 (기본 → 편집 자동 허용 → 플랜) |
| 권한 요청 | `Y` / `A` / `N` | 허용 / 항상 허용 / 거절 |

- 원칙: Claude Code에서 `Esc`는 실행 중단 키이므로, 대화창에서 나가는 키와 분리한다.
